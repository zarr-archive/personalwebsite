PERSONAL WEBSITE — MY DAILY LIFE (SLATE GRAY DARK MODE)

Halaman:
- index.html      : Beranda
- about.html      : Tentang Saya
- hobi.html       : Hobi
- aktivitas.html  : Aktivitas sehari-hari
- kontak.html     : Kontak

Folder:
- css/style.css   : CSS eksternal untuk semua halaman
- img/            : ilustrasi SVG lokal

Menjalankan:
1. Ekstrak ZIP.
2. Buka folder personal-website di VS Code.
3. Jalankan index.html di browser atau menggunakan Live Server.
4. Ganti teks profil dan kontak contoh agar sesuai dengan dirimu.

Upload ke GitHub Pages:
1. Upload seluruh isi folder ke repository GitHub, dengan index.html di root.
2. Buka Settings > Pages.
3. Pilih Deploy from a branch, branch main, folder /(root), lalu Save.
4. Tunggu hingga GitHub menampilkan alamat website.

Tema: Slate Gray Dark Mode dengan gaya elegan.
Warna utama: #171C24, #202833, #273140, aksen #94A3B8 dan teks #F1F5F9.
